# Implementation Plan: REVIEWsite

## Overview

A private quiz web app for Electronics Technician (ECT) licensure and pre-board exam review. Two users drill questions from JSON question banks, track per-subject/topic progress, and simulate real exam conditions. Built with React + Vite frontend, Node.js + Express backend, and SQLite database.

## Architecture Decisions

### Tech Stack

| Layer | Choice | Rationale |
|-------|--------|-----------|
| **Frontend** | React + Vite + TypeScript | Fast HMR dev server, SPA is fine for private app (no SSR/SEO needed). Express serves the built static files in production — single port, zero CORS issues. |
| **Styling** | Tailwind CSS + CSS variables | Mobile-first utility classes for rapid UI. Theme switching via `data-theme` attribute + CSS custom properties — instant color swap without re-renders. |
| **Charts** | Recharts | Lightweight, React-native, great for line/bar charts (score trends). Built-in `<RadarChart>` for subject competency maps. Accepts CSS variables in `stroke`/`fill` for automatic theme adaptation. |
| **Math rendering** | KaTeX | Fast LaTeX math rendering for computation questions with symbols (Σ, fractions, subscripts). Renders inline `$...$` and block `$$...$$` formulas. |
| **Backend** | Node.js + Express + TypeScript | Simple, well-known, serves both API and static frontend from one process. |
| **Database** | SQLite via Drizzle ORM + better-sqlite3 | Drizzle provides type-safe queries with zero runtime overhead on top of better-sqlite3's synchronous C++ bindings. No heavy Prisma engine binaries (important for free-tier RAM). Schema migrations via `drizzle-kit`. |
| **Auth** | Signed HttpOnly cookies + bcrypt | Immune to XSS (no token in localStorage). Clean login/logout flow. 30-day session. Pre-seeded accounts — no registration needed. |
| **Deployment** | Fly.io (persistent volume) or Render + Turso | Fly.io: 3GB free persistent volume for SQLite file. Alternative: Render free tier + Turso (cloud libSQL, 9GB free) for zero-maintenance. |

### Key Architecture Choices

1. **Monorepo structure**: `client/` + `server/` in one repo. Root `package.json` manages workspaces.
2. **Single-port production**: Express serves Vite's build output as static files + API routes. No CORS config needed.
3. **Dev proxy**: Vite dev server proxies `/api` requests to Express (`localhost:3001`). Seamless full-stack dev loop.
4. **Pre-seeded users**: No registration flow. Two accounts are seeded in the database migration. Users just log in.
5. **Server-authoritative timer**: Exam timer state stored server-side. Client timer is display-only. Server enforces time limit on submission to prevent cheating.
6. **Shared types**: `shared/types/` directory with TypeScript interfaces used by both client and server.

### Database Schema (Drizzle ORM)

```typescript
// server/src/db/schema.ts

import { sqliteTable, text, integer } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  username: text('username').unique().notNull(),
  passwordHash: text('password_hash').notNull(),
  displayName: text('display_name').notNull(),
  theme: text('theme', { enum: ['light', 'dark', 'pink'] }).default('light'),
  createdAt: text('created_at').default(sql`CURRENT_TIMESTAMP`),
});

export const examTypes = sqliteTable('exam_types', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  name: text('name').unique().notNull(),       // 'Pre-board', 'ECT'
  description: text('description'),
});

export const subjects = sqliteTable('subjects', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  examTypeId: integer('exam_type_id').notNull().references(() => examTypes.id),
  name: text('name').notNull(),                 // 'MATH', 'GEAS', etc.
});

export const topics = sqliteTable('topics', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  subjectId: integer('subject_id').notNull().references(() => subjects.id),
  name: text('name').notNull(),
});

export const questions = sqliteTable('questions', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  topicId: integer('topic_id').notNull().references(() => topics.id),
  text: text('text').notNull(),
  type: text('type', { enum: ['conceptual', 'computation'] }).notNull(),
  choices: text('choices').notNull(),            // JSON stringified array
  correctAnswer: integer('correct_answer').notNull(),  // 0-indexed
  explanation: text('explanation'),
  createdAt: text('created_at').default(sql`CURRENT_TIMESTAMP`),
});

export const quizSessions = sqliteTable('quiz_sessions', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  userId: integer('user_id').notNull().references(() => users.id),
  mode: text('mode', { enum: ['practice', 'exam'] }).notNull(),
  examTypeId: integer('exam_type_id').references(() => examTypes.id),
  subjectId: integer('subject_id').references(() => subjects.id),
  topicId: integer('topic_id').references(() => topics.id),
  questionTypeFilter: text('question_type_filter', {
    enum: ['conceptual', 'computation', 'mix']
  }),
  totalQuestions: integer('total_questions').notNull(),
  correctAnswers: integer('correct_answers').default(0),
  timeLimitSeconds: integer('time_limit_seconds'),    // NULL for practice
  timeSpentSeconds: integer('time_spent_seconds'),
  completed: integer('completed', { mode: 'boolean' }).default(false),
  startedAt: text('started_at').default(sql`CURRENT_TIMESTAMP`),
  completedAt: text('completed_at'),
});

export const quizAnswers = sqliteTable('quiz_answers', {
  id: integer('id').primaryKey({ autoIncrement: true }),
  sessionId: integer('session_id').notNull().references(() => quizSessions.id),
  questionId: integer('question_id').notNull().references(() => questions.id),
  selectedAnswer: integer('selected_answer'),     // NULL if unanswered
  isCorrect: integer('is_correct', { mode: 'boolean' }),
  answeredAt: text('answered_at'),
});
```

### API Routes

```
Auth
  POST   /api/auth/login              → Login with username/password, set signed cookie
  POST   /api/auth/logout             → Clear session cookie
  GET    /api/auth/me                 → Get current user info (id, name, theme)
  PUT    /api/auth/theme              → Update user theme preference

Questions
  POST   /api/questions/upload        → Upload & import JSON question bank
  GET    /api/questions/counts        → Question counts grouped by exam/subject/topic
  GET    /api/questions/sample        → Get sample JSON template for AI extraction

Quiz
  POST   /api/quiz/start              → Start quiz session (practice or exam)
  GET    /api/quiz/:sessionId         → Get session info + questions
  POST   /api/quiz/:sessionId/answer  → Submit answer for a question
  POST   /api/quiz/:sessionId/submit  → Submit/complete the entire quiz
  GET    /api/quiz/:sessionId/review  → Get full review with explanations

Progress
  GET    /api/progress/overview       → Overall stats: total answered, accuracy, streaks
  GET    /api/progress/subjects       → Per-subject accuracy breakdown
  GET    /api/progress/topics/:subjectId → Per-topic breakdown within a subject
  GET    /api/progress/history        → Score history over time (for trend chart)
  GET    /api/progress/sessions       → Recent quiz session history
```
